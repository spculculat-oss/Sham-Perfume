# أوقات الصلاة والأذان والأذكار

الأداة اختيارية في بطاقة الساعة، جنب بوصلة القبلة في الرئيسية، وتحت «أدوات الساعة» في باقي الأقسام. مش بتطلب موقع أو إذن صوت أو تنبيه عند الدخول، ومش بتنزّل تسجيلات إلا عند تجربة صوت أو دخول وقت صلاة اختار الزائر تنبيهها بالصوت. «إخفاء الأداة وإيقاف التنبيهات» بيحوّل الكارت لرابط صغير لإظهاره تاني.

## المكان والمواعيد

- نفس نتيجة `/api/geo` التقريبية (بلد/مدينة أو إحداثيات شبكة الدخول)، وليست هي بلد الشراء أو لغة واجهة الموقع. لما الموقع مش معروف، منطقة توقيت الجهاز أو بلد الدخول بتقترح مدينة **مكتوب عليها إنها مقترحة**؛ ما ينفعش تعتمد عليها للتنبيه قبل التأكيد. لا توجد مدينة مصرية مفروضة لو المكان مش معروف.
- اختيار البلد والمدينة بيستخدم دليل محلي قابل للبحث بالعربي أو بالاسم اللاتيني. للدولة الواحدة ممكن تظهر أكتر من منطقة توقيت. الموقع الأدق اختياري بزر مستقل؛ الإحداثيات ما بتطلعش من الصفحة، ولا بتتخزن. [tz-lookup](https://github.com/photostructure/tz-lookup) تقريب للحدود الزمنية؛ قرب الحدود، تأكد من التوقيت أو اختار مدينة أقرب. لا نطلب الموقع لمجرد إن المتصفح سمح به لأداة الطقس أو القبلة.
- [GeoNames `cities15000`](https://www.geonames.org/export/) ([CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)) للأسماء والإحداثيات والمناطق الزمنية، و[Natural Earth](https://www.naturalearthdata.com/) (public domain) لبعض الأسماء العربية. `src/data/prayerCities.tsv` مقتطف من [جدول Mawaqeet](https://github.com/ag2273/MyPrayers/blob/main/app/src/main/assets/cities.tsv) (Git blob `8a15cedf91ec3cbcf7440854f0bfaf25d32a325b`). احتفظنا بأول ٢٥ مدينة لكل بلد/إقليم بالترتيب السكاني من المصدر، أو ٤٥ لـ US/CA/AU/RU/BR/ID/MX/KZ/CN، وبأول خمس مدن متاحة لكل منطقة زمنية أيضًا. يُضم لمدن المنصة المترجمة وقت فتح الأداة. الدليل مش حصر لكل القرى والمدن. مفيش بحث خارجي عن المدينة أو جمع بيانات في البناء.
- الحساب الفلكي محليًا بـ [Adhan JS 4.4.6](https://github.com/batoulapps/adhan-js) (MIT). يخدم كل مكان حسب إحداثياته وتاريخه المدني وتوقيته الصيفي/الشتوي. وضع «تلقائي» يختار طريقة شائعة للبلد (زي الهيئة المصرية، أم القرى، كراتشي، ISNA أو غيرهم) وإلا رابطة العالم الإسلامي؛ يقدر الزائر يختار طريقة أخرى، أو يغيّر حساب العصر. أم القرى تستخدم ١٢٠ دقيقة للعشاء في رمضان وفق تقويم أم القرى التقريبي، وإلا ٩٠ دقيقة. في خطوط العرض العالية قد يُقدّر الشفق بجزء من الليل أو حسب طريقة لجنة رؤية الهلال؛ لو المواعيد ناقصة أو غير مرتبة (زي النهار القطبي)، ما نعملش تنبيه لجدول اليوم الناقص. الشروق للعرض فقط.
- المواعيد تقديرية، مش جدول رسمي أو بديل لإعلان المسجد. للتحقق: [بوابة الأهرام، ١٨ نوفمبر ٢٠٢٦](https://gate.ahram.org.eg/News/5981868.aspx)، القاهرة: `04:52 06:22 11:40 14:37 16:57 18:18`. حساب مركز القاهرة بالهيئة المصرية: `04:52 06:22 11:41 14:37 16:58 18:18`. `tests/prayerTimes.test.ts` يختبر فرق الدقيقة والتواريخ وحدود التوقيت، بما فيها العشاء اللي يدخل بعد منتصف الليل ويظل تابع لجدول اليوم السابق.

## التذكير والصوت

- التذكير الصامت على الصفحة أو بصوت الأذان محتاج اختيار صريح **في كل صفحة جديدة**. يفضل نشط أثناء التنقل الداخلي بس، على ساعة الجهاز. مفيش تنبيه نظام أو خدمة تعمل بعد القفل، وممكن الجهاز يوقّف صفحة في الخلفية. لو المتصفح رجع خلال دقيقة من الموعد وكانت الأداة شغالة قبل الموعد، ممكن تظهر التذكرة؛ الفائت الأقدم مش بيتعاد. الحالة الأولية دايمًا «إيقاف التنبيه».
- أداة الصوت تفتح Web Audio من زر التفعيل/التجربة، ولا تستخدم مقطع ساكت مستمر. التنبيه يظهر على الصفحة لو الصوت غير متاح. اختيار الفجر منفصل عن باقي الصلوات؛ مش بنشغّل أذان عادي بدل الفجر. تقدر توقف التسجيل الحالي، توقف كل التذكيرات، أو تخفي الأداة. بنمنع تكرار نفس الصلاة في الصفحة، ونستخدم Web Locks مع علامة محلية قصيرة لمنع تكرار الأذان بين التبويبات عند دعم المتصفح.
- تفضيلات المدينة والطريقة والصلوات والأصوات المضمنة والإخفاء على الجهاز فقط، ضمن مسح وتصدير بيانات المنصة. لا نحفظ إحداثيات GPS، ولا الصوت المرفوع، ولا إذن تشغيل دائم أو سجل صلوات. اختيار ملف من الجهاز (حتى ١٢ MiB / صوت حتى ٨ دقائق، حسب ما المتصفح يقدر يشغّل) بيشتغل في الجلسة فقط؛ اختار تسجيل فجر للفجر.

## المكتبة

`src/data/prayerAdhkar.ts` اختيار موضوعي من صيغ الذكر والدعاء بالعربي من مصادرها التراثية المبينة لكل ذكر. ليست نسخة من ترتيب أو تعليقات أو ترجمة حديثة لكتاب. العدّاد للتكرارات المذكورة، في الواجهة فقط. [طبعة «حصن المسلم» الكاملة على دار الإسلام](https://islamhouse.com/read/ar/حصن-المسلم-من-أذكار-الكتاب-والسنة-2522) مفتوحة للقراءة برابط منفصل، وليست منسوخة في الموقع. `src/data/prayerQuran.txt` آيات مختارة دون تغيير الكتابة من نسخة Tanzil Quran Text (Uthmani 1.1)، مع بيان الحقوق الأصلي؛ أصل النسخة في `AhmedWalid4499/Azkar`، blob `15968180ffffa45f0556fa6c81fa8c99a2a70bc8`. ## تحقق محلي

- `npm run lint`
- `node --import tsx --import ./tests/register-assets.mjs --test tests/prayerTimes.test.ts`
- مع سيرفر المعاينة: `BROWSER_EXECUTABLE=/path/to/chromium CLOCK_BASE_URL=http://127.0.0.1:3000/ node scripts/check-prayer-tools.mjs`
- `npm run build:vercel && npm run test:vercel`، و`VITE_API_BASE_URL=https://sham-perfume-49bf.vercel.app npm run build:pages` ثم `VITE_API_BASE_URL=https://sham-perfume-49bf.vercel.app npm run check:pages`. التسجيلات تتقدّم من نفس أصل الموقع وتحترم بادئة `/Sham-Perfume/` على Pages. لاختبارها في المتصفح على بناء Pages، شغّل الاختبار بـ`PRAYER_SCENARIO=pages` مع رابط المعاينة بالبادئة في `CLOCK_BASE_URL` وأصل الـAPI في `PRAYER_API_ORIGIN`.
