# الكتيّبات الأصلية الأولى

كتيّبان عربيان أصليان قصيران، لكل منهما ستة فصول وثلاث فقرات في كل فصل:
- لغة الرائحة: دفتر الملاحظة والمقارنة.
- دفتر الباحث في العطور: من السؤال إلى الدليل.

هذه مادة تعليمية تمهيدية بمساعدة الذكاء الاصطناعي، وليست تلخيصاً أو ترجمة للمراجع المحمية، وليست كتب التأليف العلمي الثلاثة المخطط لها أو مراجعة توافق الكتب القديمة مع العلم الحديث. لا تتضمن نسب خلط أو جرعات أو ادعاءات علاجية. لم تسجل موافقة قانونية أو علمية مزعومة.

المحتوى في `content/library/scent-observation.json` و`content/library/evidence-notebook.json`. التوليد: `python3 scripts/build-library-epub.py --all`. ملفات الإنتاج في `public/books/`. ينتج نفس النص في القراءة الاحتياطية وEPUB، ويفصل رف المتاح للقراءة عن فهرس المراجع غير المرفقة. تستخدم الواجهة العربية والإنجليزية مع احتياطي اللغات المعتاد؛ نصوص الكتيبات بالعربية فقط ولا تدعي ترجمتها.

أي محتوى علاجي أو كيميائي تطبيقي تفصيلي لاحق يحتاج مصادر وتقييم علمي وسلامة متخصصين. هذه البداية اختيرت لتمكين قراءة مفيدة فعلية دون نسخ الكتب أو اختلاق مراجعتها.
