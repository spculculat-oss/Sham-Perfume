# أرشيف شاهين للدراسة الداخلية

بتوجيه صاحب الموقع، ملاحظات دراسة المراجع ليست كتباً للعرض العام، وإنما مادة إعداد داخلية محتملة لدعم شاهين.

## ما تم فعلاً
- تسجيل المراجع الستة عشر وروابط اكتشافها السابقة وملاحظات اختلاف الطبعات/المؤلفين في `server/library/bookStudyArchive.ts`.
- كل مرجع حالته انتظار مصدر قانوني، لم تقرأ نصوصه الكاملة ولم تقارن ادعاءاته علمياً بعد. وصف الناشر ليس دليلاً علمياً على صحة محتواه.
- ربط ملخص حالة الأرشيف بموجز مجلس شاهين وسجل تشغيل المدرسة، دون إدخاله في بنك الأسئلة أو إجابات الزوار أو ذاكرة التعلم.
- نسخة محلية يمكن توليدها بالأمر `node --import tsx scripts/library/archive-study.mts` داخل `.data/library/` المتجاهل من Git. إعادة التوليد تصدر سجل التخطيط الحالي فقط، ولا تدمج أو تحفظ ملاحظات دراسية لاحقة.

## الحدود
- هذا أرشيف برمجي داخلي غير مستورد من الواجهة ولا يوجد له مسار API عام. المستودع نفسه قد يكون عاماً؛ هذه ليست خزنة سرية. لا تحفظ به ملفات مرخصة أو بيانات حساسة.
- ليس رفعاً إلى قاعدة بيانات شاهين الحية أو تدريباً لنموذج. المجلس والمدرسة يقرآن الحالة عند تشغيل النسخة التي تضم التغيير، وليس قبل نشرها.
- لا أضيف ملاحظات من كتب لم أقرأها ولا أختلق اعتماداً قانونياً أو علمياً.
- الاستخدام الداخلي لا يمنح تلقائياً حق نسخ/تحويل/تدريب النصوص المحمية. يراجع المدير القانوني شروط المعالجة المقصودة، وتخزن الملفات المسموحة خارج Git وpublic في مخزن مقيد الوصول.
- لإكمال الدراسة: تحديد طبعة ومصدر متاح قانونياً، قراءة أقسام موثقة، تسجيل ادعاءات مع صفحاتها، مقارنة بمصادر علمية حديثة مستقلة وتواريخها، ثم مراجعة المختص والحقوق. إدخال النتائج المعتمدة في معرفة شاهين يحتاج مساراً منفصلاً لا يسرّب النصوص أو الملاحظات الداخلية إلى المتصفح.
- بطاقات الفهرس العامة السابقة لم تتغير؛ عدم عرض الدراسة لا يعني إخفاء أسماء المراجع التي سبق نشرها. الأرشيف الداخلي لا ينشر كتباً أو ملخصات للزوار.
