# قارئ EPUB

- الضغط على عنوان المرجع أو «فتح الكتاب · EPUB» يفتح نافذة حوار أصلية داخل الصفحة. Escape وزر الإغلاق يعيدان التركيز للزر السابق، مع حجز التركيز ومنع تمرير الخلفية.
- لا توجد نسخ EPUB مرفقة للمراجع الستة عشر. يظل تصدير الفهرس تصديراً للبيانات فقط؛ لا تُحوّل الأوصاف إلى نصوص كتب مزعومة.
- يستطيع الزائر اختيار نسخة EPUB من جهازه يحق له قراءتها. تُقرأ في ذاكرة المتصفح فقط؛ لا نرفعها أو نخزنها أو نربطها تلقائياً بمرجع منشور. يجب على المستخدم التحقق من مطابقة الملف للعنوان.
- يدعم القارئ التنقل بين الصفحات وفهرس الفصول. يدعم EPUB غير المحمي بـDRM، ولا يتجاوز الحماية. الحد الأقصى لحجم الملف المضغوط 20 ميجابايت؛ ليس ضماناً ضد الملفات المضغوطة الخبيثة، فيجب استخدام ملفات موثوقة.
- تُحمَّل مكتبة epub.js عند الحاجة فقط. محتوى الفصول داخل sandbox دون السماح بالسكريبتات أو النوافذ المنبثقة، مع سياسة CSP تمنع طلبات الشبكة من الفصول وتسمح بموارد blob/data المحلية. تُزال العناصر النشطة وعمليات إعادة التوجيه من الفصول قبل العرض. لا يهدف القارئ لدعم محتوى تفاعلي أو أصول بعيدة، وقد لا تعمل بعض الملفات غير القياسية.
- أخطاء القراءة/التشفير والملفات الكبيرة أو ذات الصيغة المختلفة تظهر رسالة قابلة للتعافي باختيار ملف آخر. تغيير الملف أو إغلاق النافذة يدمر جلسة القراءة ويحرر الموارد.
- إرفاق نسخة رسمية لكل عنوان مستقبلاً يتطلب ملفاً مرخصاً وتوثيق الحقوق؛ لا توجد موافقة نشر ضمنية من فتح نسخة شخصية.

فحص يدوي مقترح: افتح كتاباً بلوحة المفاتيح، جرّب Escape وإعادة التركيز، ملف EPUB موثوق بفصول متعددة، التنقل والفهرس على الهاتف، ملف تالف، تغيير الملف أثناء التحميل، وفتح وإغلاق النافذة عدة مرات. اختبارات الوحدة لا تحل محل اختبار العرض الفعلي في المتصفح.

## بيئة الإنتاج والقراءة المباشرة
- المصدر الأصلي القابل للتحرير: `content/library/reading-guide.json`؛ مولد EPUB حتمي: `python3 scripts/build-library-epub.py`، بدون خدمات خارجية أو مفاتيح.
- الملف المنشور: `public/books/sham-reading-guide.epub`؛ ينسخه بناء Vite إلى بيئة Pages تلقائياً. مسار القراءة يحترم `BASE_URL`، ويعمل تحت `/Sham-Perfume/` أو جذر الموقع.
- الدليل تمهيدي قصير بالعربية ومفصول عن المراجع العلمية الستة عشر. لا يمثل كتب التأليف الثلاثة المخطط لها ولا مراجعة علمية. بطاقة واضحة تفصح عن الاستعانة بالذكاء الاصطناعي.
- إضافة مراجع كاملة تتطلب توفير الملفات المرخصة أولاً، ثم إدراج مساراتها المحلية الموثقة؛ لا روابط عشوائية أو تحويل لسجلات الفهرس إلى كتب مزعومة.
- التشغيل: `bun install --frozen-lockfile`، ثم `npm run dev`. التحقق: `npm run lint` و`npm test` و`npm run build:pages`. مسار النشر المعتاد هو PR بفحوص ناجحة ثم الدمج وGitHub Pages.
