# منظومة بحث شاهين الموجهة

تطوير للباحث الحالي، وليست محرك بحث شاملًا بحجم جوجل أو زاحفًا لكل الإنترنت.

## مسار المعلومة

1. ذاكرة شاهين ومكتبته ومحركاته الحالية تظل كما هي؛ البحث الخارجي يعمل في مسار الرجوع عند عدم وجود إجابة.
2. يحلل الباحث السؤال ويرفض البحث عن المعلومات الشخصية أو الأخبار والأسعار اللحظية.
3. يبحث بصيغ متعددة بالتوازي عبر واجهة ويكيبيديا الرسمية، ثم يقرأ المقالات الأعلى صلة بالتوازي.
4. يرتب المقاطع بحسب الصلة والتشابه بين المقالات ويحذف الأفكار المكررة. التشابه ليس تحققًا مستقلًا من صحة المعلومة.
5. يعرض المقتطفات وروابط المصدر وتنبيه المراجعة ورخصة CC BY-SA. لا يولد إجابة مزيفة عند فشل المصدر.

## السرعة والحماية

- ذاكرة مؤقتة للمستندات العامة فقط، لا للأسئلة أو الإجابات: 150 مستندًا، ربع ساعة لكل مستند.
- دمج تنزيل نفس المستند بين الأسئلة المتزامنة؛ حتى 3 طلبات خارجية في الوقت نفسه و30 عملية قيد التنفيذ/الانتظار.
- حد 512 ألف بايت للاستجابة، مهلة للشبكة، وعدم تخزين الإخفاقات.
- طلبات HTTPS إلى واجهة ويكيبيديا الرسمية فقط، دون روابط يقدمها الزائر أو صفحات نتائج محركات البحث.
- الذاكرة داخل عملية الخادم أو تبويب المتصفح؛ ليست قاعدة بيانات دائمة أو مشتركة بين نسخ الخادم. قد تختفي مع إعادة التشغيل.
- يعمل على الخادم وفي بديل البحث بالمتصفح على الموقع الثابت. لا يحتاج مفتاحًا جديدًا.
- لا توجد دورة زحف خلفية أو تتبع عام لروابط المواقع. التوسع لمصادر أخرى يحتاج موصلات رسمية ومراجعة شروط كل مصدر.

## التشغيل والتحقق

الخادم يحترم مفتاح `SHAM_WEB_RESEARCH` الحالي (`off` للإيقاف، `on` للتفعيل). في الإنتاج يعمل افتراضيًا وفق إعداد الباحث الحالي. الموقع الثابت يحتاج وصول المتصفح إلى واجهة المصدر.

الاختبارات تستخدم مصادر وهمية ولا تثبت إتاحة ويكيبيديا من شبكة النشر؛ البيئة الحالية لا تسمح باتصالات ويكيبيديا، لذلك لم يُجر اختبار حي أو قياس سرعة حقيقية.

الملفات: `src/utils/researchSpider.ts`، `src/utils/webResearch.ts`، `server/shaheen.ts`، `src/utils/browserMemory.ts`.

التحقق: `npm run lint`، `npm test`، `npm run build`.
