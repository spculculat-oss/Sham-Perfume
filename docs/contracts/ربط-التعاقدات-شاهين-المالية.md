# ربط التعاقدات مع شاهين والإدارة المالية

> تنفيذ طلب شاهين: «أي عقد يكتمل تعاقده فوراً يتم عمل كونتاكت مع شاهين لينزله على المتجر + ربط ومراجعة مع الإدارة المالية»

## المسار الجديد بعد الاعتماد (C-10)

```
التوقيع (view → sign) → تأكيد الإيميل (confirm-reply / email_code)
        ↓
اعتماد المدير القانوني POST /api/admin/contracts/:id/approve
        ↓
server/contracts/integration.ts:onContractApproved() فوراً
   ├─ ① شاهين: notifier.send('contract.approved', …) إلى SHAM_WEBHOOK_URL
   ├─ ② إستيراد فوري: POST /repos/:repo/actions/workflows/shaheen-import.yml/dispatches  (GITHUB_TOKEN + SHAM_GITHUB_REPO)
   └─ ③ مالية: finance.issue('CONTRACT_APPROVED') + finance.issue('MISSING_COSTS') → تظهر في /api/admin/finance + /api/admin/contracts/finance/overview
```

- **شاهين**: الحارس `scripts/shaheen-import/guard.ts` كان يقرأ `approvedStores()` كل 12 ساعة. الآن الإعتماد يدفع إشعاراً فورياً + (إن وُجد `GITHUB_TOKEN`) يشغّل الـ workflow فوراً. لو لم يُضبط الـ token يبقى الإستيراد الدوري كاحتياط.
- **المالية**: يُفتح `issue` بعنوان `عقد معتمد: rose.example — بانتظار إعداد التسعير` في `financeIssues`. `FINANCE.md` يطلب إدخال `cost/shipping/fee/tax` قبل أول طلب؛ `finance.report()` سيظهر `incomplete` حتى تُدخل. السحب (`revoke` → C-07) يُغلق الـ issues تلقائياً (`resolvedAt`).

## الإعداد

```bash
# إشعار شاهين (Slack/Discord/n8n→WhatsApp/Telegram/Email)
SHAM_WEBHOOK_URL=https://hooks.example/shaheen
SHAM_WEBHOOK_SECRET=…      # يوقّع HMAC-SHA256 → X-Sham-Signature

# دفع إستيراد فوري (اختياري)
GITHUB_TOKEN=ghp_…          # repo scope على spculculat-oss/Sham-Perfume
SHAM_GITHUB_REPO=spculculat-oss/Sham-Perfume
SHAM_IMPORT_WORKFLOW=shaheen-import.yml
SHAM_IMPORT_REF=main

# المالية
SHAM_FINANCE_TIMEZONE=Africa/Cairo
SHAM_STORE=file             # أو memory/firestore — نفس متجر Sham Core
```

## الواجهات

- `POST /api/admin/contracts/:id/approve` → `{ contract, integration: { shaheenNotified, shaheenDispatched, financeLinked, details } }`
- `GET /api/admin/contracts/finance/overview` → `{ approved, financeIssues, linkedAt }` — تُعرض في `src/admin/ContractsPanel.tsx` كـ «الربط مع الإدارة المالية»
- `GET /api/admin/finance/` (Dashboard أمين شاهين) يظهر `CONTRACT_APPROVED` ضمن `openIssues`

## الواجهة (ContractsPanel)

- بعد الضغط «اعتماد المدير القانوني» يظهر بنر أخضر: شاهين notified/dispatched + finance linked.
- قسم جديد «الربط مع الإدارة المالية — عقود معتمدة بانتظار المراجعة» يسرد `approved` + عدد `financeIssues`.
- `revoke` يزيل المتجر من `approvedStores` خلال 48 ساعة (C-07) ويُغلق الـ issues المالية.

## المراجع القانونية

- L-40: `docs/legal/رأي-المدير-القانوني-نظام-التعاقدات.md` — التوقيع الإلكتروني ساري (ماليزيا 2006 + مصر 15/2004).
- L-03 + guard.ts: الاستيراد محجوب بدون إذن كتابي أو عقد معتمد.
- FINANCE.md: append-only ledger، لا استرداد/دفع تلقائي، المراجعة يدوية.
