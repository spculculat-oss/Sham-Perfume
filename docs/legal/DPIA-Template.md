# DPIA — تقييم أثر حماية البيانات (L-25)
## Data Protection Impact Assessment — GDPR Art.35 / SA PDPL

> يُنفذ قبل إطلاق أي معالجة عالية المخاطر. هذا القالب جاهز لـ 3 وحدات حساسة: Auth + Community (موقع/عمر) + Shaheen AI.

### 1) وصف المعالجة
| وحدة | بيانات | غرض | أساس قانوني | هل ضروري؟ |
|---|---|---|---|---|
| Auth | اسم/بريد/هاتف/dob/بلد/hash | إدارة حساب | عقد + موافقة عمر | نعم — بدون حساب لا خدمة |
| Community | منشور/صورة/أصدقاء/رسائل/موقع تقريبي | تواصل اجتماعي | موافقة صريحة | اختياري — يمكن عدم التفعيل |
| Shaheen AI | سؤال/جواب/تاريخ/تقييم | مساعد عطري | موافقة | نعم لكن يمكن مسح فوري |

### 2) الضرورة والتناسب
- هل يمكن تحقيق الغرض ببيانات أقل؟ **لا** — كل حقل له وظيفة (dob للعمر القانوني، بلد للشحن/VAT)
- هل المعالجة توقعات معقولة للمستخدم؟ **نعم** — موضح في Privacy Center

### 3) تقييم المخاطر
| خطر | احتمال | أثر | تدبير |
|---|---|---|---|
| تسرب كلمة مرور | منخفض (بعد L-01: hash SHA-256 + server Argon2) | عالي | تشفير + HttpOnly + CSP |
| تنمر/كراهية في المجتمع | متوسط | عالي | ReportButton 24h + فلتر + مشرف |
| هلوسة AI تعطي نسبة كحول خاطئة | متوسط | متوسط | إخلاء IFRA + وسم AI + تحقق بشري |
| تتبع موقع بدون موافقة | منخفض (بعد CMP) | عالي | CMP + لا تتبع قبل موافقة |
| طفل <13 يسجل | منخفض (بعد L-17: dob+13) | عالي | منع <13 + حذف تلقائي |

### 4) تدابير إضافية
- تشفير AES-256-GCM للبنوك (L-10)، RoPA (L-22)، احتفاظ محدد (L-23)، خطة خرق 72h (L-16)، DPA مع المعالجين (L-15)
