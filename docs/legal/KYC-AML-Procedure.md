# إجراءات اعرف عميلك ومكافحة غسل الأموال — L-11/L-30
## KYC/AML Procedure — OFAC / EU Sanctions / SA AML / مصر 80/2002

### 1) من نتحقق منه
كل تاجر (Merchant) قبل تفعيل متجره. المستهلكون العاديون لا يحتاجون KYC إلا إذا طلبوا إرجاع بمبالغ كبيرة متكررة.

### 2) مستندات مطلوبة (مرحلة يدوية — مجاني)
- سجل تجاري ساري + هوية/جواز المؤسس
- إثبات عنوان (فاتورة كهرباء/سجل ضريبي)
- صور المنتجات/المخزون (إثبات ملكية أو تفويض مورد)
- IBAN (يُشفر AES-256-GCM — L-10)

### 3) فحص
- مطابقة الاسم مع **OFAC SDN** + **EU Consolidated Sanctions** (بحث يدوي أولًا: https://sanctionssearch.ofac.treas.gov + https://www.sanctionsmap.eu)
- فحص CITES/REACH إذا يبيع عود/مواد مقيدة
- مكالمة فيديو 5 دقائق للتحقق من الهوية (مسجلة بموافقة)

### 4) قرار
| حالة | معنى | صلاحيات |
|---|---|---|
| pending | تحت المراجعة (≤48 ساعة) | يعرض منتجاته لكن غير قابل للطلب |
| approved | تم التحقق | يمكن البيع |
| suspended | شبهة/انتهاء مستند | يُجمّد + إشعار + 14 يوم لتصحيح |
| rejected | وثائق مزورة/عقوبات | مرفوض نهائي + بلاغ FIU إذا لزم |

### 5) مراقبة مستمرة (AML)
- تنبيه إذا: طلب واحد > $5,000، أو 10 إرجاعات/شهر، أو شحن لدول محظورة (SY/IR/KP/RU)
- تجميد + مراجعة + إبلاغ FIU (مصر: وحدة مكافحة غسل الأموال، السعودية: رئاسة أمن الدولة)

### 6) آلي لاحقًا (90 يوم — $100-300/شهر)
- SumSub / Veriff للتحقق الآلي + فحص OFAC API
